# storefront-sim

محاكاة حمل رندر صفحة المتجر في `core-service`، لقياس عدد الزوار في الثانية.

## ليه محاكاة مش قياس على الخدمة نفسها

`core-service` محتاج MongoDB وRedis وRabbitMQ، ومفيش ولا واحد منهم شغال على
الجهاز ده (ولا Docker). فالمحاكاة بتشغّل **شغل المعالج الحقيقي** (ترجمة Nunjucks،
بناء شجرة البيانات، معالجة الحقول) وبتخلي زمن الـ I/O بارامتر.

ده مش تبسيط مخل: في Node اللي بيحدد السقف هو زمن المعالج، لأن انتظار الـ I/O
بيتداخل بين الطلبات. `MONGO_MS` و`REDIS_MS` قابلين للضبط لو حبيت تجرب أرقام تانية.

## اللي اتحاكى — ومن فين

| المرحلة | المصدر في core-service |
|---|---|
| حل المتجر والدومين والدولة والسوق | `front/middlewares/store-context.middleware.ts` (٢١ await) |
| إنشاء الجهاز والجلسة — **كتابات لكل زائر** | `front/middlewares/init.middleware.ts` |
| الثيم وإعداداته والترجمات | `front/middlewares/theme.middleware.ts` |
| جلب الصفحة والتمبلتس والبلوكات | `render/services/get-final-widgets-for-render.service.ts` |
| معالجة كل حقل في كل ويدجت وبلوك | `processing/widget-process/*` |
| رندر Nunjucks | `front/services/final-render.service.ts` + `nunjucks/nunjucks.service.ts` |

الصفحة المحاكاة: ١٠ أقسام (هيدر بقائمة، بانرات، ٣ شبكات منتجات، فوتر)، ٣ بلوكات
لكل قسم، ١٢ منتج في الشبكة. الناتج **٨٨ كيلوبايت HTML** و**٢١ استعلام مونجو**
و**٤ عمليات ريدس** للصفحة الواحدة.

## التشغيل

```bash
npm install

# الكود زي ما هو دلوقتي
node src/server.js

# بعد الإصلاحات التلاتة
SIM_MODE=tuned node src/server.js

# إصلاح واحد بس
NJK_CACHE=1 node src/server.js

# بعدد الأنوية
WORKERS=6 node src/cluster.js

# حساب الطاقة من ميزانية الإعلانات
node capacity.js
CPC=1.5 MERCHANTS=400 node capacity.js
```

`/stats` بيرجّع زمن الرندر وعدد الاستعلامات للطلب الواحد.

## الأعلام

| العلم | الإصلاح المقابل |
|---|---|
| `NJK_CACHE=1` | كاش قوالب Nunjucks بدل `noCache: true` |
| `PAGE_CACHE=1` | تفعيل قراءة كاش الصفحة المتعلّقة في السطور ٣٩–٤٦ |
| `PARALLEL_FIELDS=1` | معالجة حقول الويدجت بالتوازي بدل التتابع |
| `SIM_MODE=tuned` | التلاتة مع بعض |

## النتائج المقيسة (٦ أنوية)

| | نسخة واحدة | ٦ نسخ | CPU/طلب |
|---|---|---|---|
| الكود الحالي | ٣٤.٩ طلب/ث | ١٦٩.١ طلب/ث | ٢٩.٢٧ms |
| + كاش القوالب بس | ٥٨٦.٩ طلب/ث | — | ١.٥٠ms |
| بعد التلاتة | ٨٦١.٢ طلب/ث | ٢٥٧٠ طلب/ث | ١.١٤ms |

**كاش القوالب لوحده بيجيب ٩٥٪ من المكسب.** الإصلاحين التانيين مالهمش أثر
يُذكر قبله (٣٦.٥ و٣٦.١ طلب/ث)، وبيضيفوا ٤٥٪ بعده.

## حدود المحاكاة

الأرقام دي **حد أعلى متفائل** للكود الحقيقي، لأن المحاكاة مافيهاش:
GraphQL، الحُرّاس، Sentry، التسجيل، TLS، وزمن مونجو الحقيقي مع populate
المتداخل (أعلى من ٠.٨ms المفترضة هنا). الطاقة الفعلية أقل.
